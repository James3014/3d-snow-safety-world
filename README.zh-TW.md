# 3D Snow Safety World

[English](README.md) | 繁體中文

**開源的互動式 3D 滑雪安全學習原型**。首版包含十個雪道情境、A/B/C 三種選擇與不同後果、俯視／滑手視角／側視、正常與慢動作重播，以及繁體中文和英文。

**重要聲明：** 這是教育示意原型，不是滑雪安全認證。角色動作、距離、速度和動畫時間不能視為經實測的安全技術或急救指示。十題的完整專業動作審核、真人學習效果與實體手機測試尚未完成，不得對外宣稱已驗收或具備安全資格。

## 在電腦執行

需要 Python 3，不需要雲端 API、帳戶或安裝前端依賴。

```sh
cd site
python3 -m http.server 8080 --bind 127.0.0.1
```

使用瀏覽器開啟 `http://127.0.0.1:8080/`。使用進度只保存在目前瀏覽器的 `localStorage`，程式沒有內建外部分析 SDK 或資料上傳。

## 測試

```sh
node --test tests/*.test.cjs
```

此測試只查核程式結構、十題/三分支、檔案引用、隱私界線及基本無障礙元件，不等於 3D 畫面逐幀審查、真人學習測試或真機驗收。
