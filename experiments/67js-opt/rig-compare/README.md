# Issue #7: Reversible geometric rider A/B trial

This experiment adds one shared, geometry-only rider model to lesson 04
(crowd control), lesson 01 (blind crest), and lesson 09 (lift exit).

- Canonical poses are still generated by the original frameFor() function.
  The main Renderer67, RAF clock, phase machine, camera, speed, practice/demo,
  language and WebGL2 fallback still live only in shared/runtime.js.
- Every rider (including scene 04 ambient riders and the first-person self
  inset) is created by shared/geometric-rig.js. The rig choice selects either
  the legacy pose renderer or the geometric one without seeking or reloading.
- Blue, orange and purple accent colors are intentionally restrained. The
  candidate has a light, featureless spherical head, a light torso, thick
  articulated legs and arms, dark joints and two snowboard bindings.
  A two-ski/lateral-stance implementation is unit-tested, but all three
  actual lessons still use snowboard. It has not been E2E accepted.
- The old rig stays registered for instantaneous rollback. This increases
  registered geometry; no performance improvement is assumed.
- No original site/67js-ten/ file, UX onboarding branch, authored lesson
  timeline, decision text or historical public release is modified.

## Reproduce (Node.js >=24 and Chrome)

From the repository root on the authorized M4:

~~~sh
export PATH=/opt/homebrew/bin:$PATH
node --test experiments/67js-opt/tests/rig-issue7.test.mjs
sh experiments/67js-opt/scripts/build-rig-preview.sh
python3 -m http.server 8596 --bind 127.0.0.1 \
  --directory "$HOME/workspace/3d-snow-safety-rig-preview-20261113"
~~~

Open http://127.0.0.1:8596/ for the three-lesson dual-iframe
comparison. Both iframes use the same authored pose, branch and camera.
Each lesson also has a standalone 切換簡化人形 button. The private
preview is built outside the tracked GitHub Pages site/ directory.

To repeat M4 Chrome checks after also serving unchanged site/ at
127.0.0.1:8597:

~~~sh
node experiments/67js-opt/tests/rig-browser-e2e.cjs
node experiments/67js-opt/tests/rig-regression.cjs
node experiments/67js-opt/tests/rig-performance.cjs
node experiments/67js-opt/tests/rig-contact-sheet.cjs
~~~

Pixel screenshots and machine-readable JSON are written to the private
~/workspace/3d-snow-safety-rig-preview-20261113/qa/ directory by default.
Curated scrubbed screenshots are in docs/rig-issue7-evidence/ for review.
