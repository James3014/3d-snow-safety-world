# Security Policy

This is an early-stage educational prototype, not an actively supported production service. Avoid posting vulnerabilities that expose private credentials, accounts or personal data in a public Issue. Use GitHub's private vulnerability reporting if enabled for the repository; otherwise contact a repository maintainer through a private channel.

The software has no back-end and does not require API keys. Browser progress is saved locally. Do not add external telemetry or publish real-user data as part of bug reports. This repository intentionally does not deploy a public website.
