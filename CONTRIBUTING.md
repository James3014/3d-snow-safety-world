# Contributing

Before a pull request, run `node --test tests/*.test.cjs` and load every affected scenario in a real browser. State the exact scene ID, A/B/C branch, before/after behavior, desktop/mobile viewport, and any unresolved negative test. For safety-related content, cite the relevant resort or official guidance and distinguish animation assumptions from established facts.

Please preserve existing bilingual content and progress storage semantics. No new external analytics, credential access, public hosting or tracking without explicit project-owner approval. Never include internal QA reports, screenshots of private sessions, IP addresses or private server configuration.

The repository is a prototype. Contributions are not certification, professional safety sign-off or approval for public deployment.
